# Verify: 消息搜索与筛选 · spec 0013 · updated 2026-11-05
_Steps derived from spec 0013 acceptance criteria. `/check verify` runs these; `/test` locks the durable ones._

## UI / manual
- [ ] 打开 `/search`，图标栏「搜索」高亮；不输入任何条件 → 显示「输入关键词或选择筛选条件」，网络面板没有 `/api/search/messages` 请求 → AC-1, AC-2
- [ ] 搜「空投 btc」后刷新、前进后退、复制网址到新标签页 → 条件和结果一致 → AC-1
- [ ] 输入 `a`、`-a`、201 个字符、11 个词 → 输入框下方出现对应原因，不发请求；只输入 `-foo` 且无筛选 → 提示需要筛选 → AC-4
- [ ] 搜 `"止损 位"`、`btc -"止损 位"`、`--foo`、`a"b`、`50%` → 结果符合语法细则 → AC-3, AC-5
- [ ] 搜只出现在 embed 描述、转发正文、已移除附件文件名里的词；搜 `pepe`；搜提及里的用户 ID 数字 → 前者命中，后者搜不到 → AC-6
- [ ] 结果里能看到已关闭采集和已删除频道的消息、已删除消息的删除标记 → AC-7
- [ ] 选择器：按服务器分组、可搜名字、勾选父频道会带上线程、勾选单个频道不带同分类其他频道、勾选超过 200 个频道被拦住 → AC-8
- [ ] 作者联想：大小写不敏感、最多 20 个候选、多选、点结果作者名加入筛选、选满 20 人提示；刷新后名字还原 → AC-9
- [ ] 时间：今天 / 最近 7 天 / 最近 30 天 / 自定义；刷新后快捷项仍是相对值；开始不早于结束时输入处就提示 → AC-10
- [ ] 同时叠加关键词、频道、作者、时间 → 取交集 → AC-11
- [ ] 翻页：滚到底自动加载，不重复不遗漏；卡片头部显示服务器、频道（线程显示「父频道 › 线程」）和状态标记 → AC-12
- [ ] 命中词高亮（大小写不同、短语含多个空格都高亮；`**B**TC` 不高亮也不报错） → AC-13
- [ ] 顶部总数；超过 1000 显示「1000+ 条」；点「刷新」立刻从第一页重取（没有相对时间范围时也要重取，这次修过） → AC-14, AC-15
- [ ] 第一页加载骨架、失败有错误块和重试、无结果提示、第二页失败保留已有结果；宽度小于 768px 时筛选收进面板 → AC-16
- [ ] 点「跳到上下文」→ 频道页目标居中并高亮约 2 秒，上下都能继续滚；系统开启减少动画时不淡出 → AC-17
- [ ] 手改网址 `m=` 指向别的频道的消息 → 提示「找不到这条消息，已显示最新消息」，网址去掉 `m` → AC-18
- [ ] 以某条为中心浏览时，实时新消息不追加、不跳底、不上报已读；向下翻到最新后恢复；「回到最新」可用 → AC-19
- [ ] 把部分行的 `search_text` 置空 → 顶部横幅显示剩余条数，30 秒刷新，补完后消失 → AC-22, AC-23
- [ ] 大数据量下搜常见词不加筛选 → 约 10 秒后显示「这次搜索太慢了」和重试 → AC-24
